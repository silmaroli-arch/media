Gerar Excel a partir de PDF

Envie o PDF do preparo (com texto selecionável, não escaneado como imagem). O sistema extrai o texto e tenta identificar automaticamente algumas regras (jejum, cortes de líquido/sólido em horas antes do exame, medicamentos a suspender com seus prazos em dias antes, alimentos permitidos/ proibidos) — é uma extração simples, por palavras-chave, sem inteligência artificial.

O resultado é baixado como uma planilha Excel (.xlsx) pronta pra você revisar e ajustar com calma — nada é salvo no sistema aqui. Depois, use o botão "Importar de um Excel" na tela de novo modelo de preparo para trazer os dados revisados pro cadastro. Disponível apenas na versão web — no app, o cadastro de modelo de preparo é sempre manual.
